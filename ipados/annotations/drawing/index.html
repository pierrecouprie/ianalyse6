Dessiner sur le Document

Le dessin permet d’ajouter une annotation libre directement dans le Document. Sur iPadOS, cette fonction utilise PencilKit et peut être utilisée avec l’Apple Pencil.

Créer une annotation dessinée​

Placez la tête de lecture au moment où le dessin doit apparaître, puis choisissez l’annotation de dessin. Dessinez ensuite directement dans la vue principale du Document.

Le dessin devient une annotation temporelle : il peut donc avoir un début, une fin, un calque et des propriétés visuelles.

Utiliser PencilKit​

La palette PencilKit permet de choisir les outils de dessin disponibles sur iPadOS : crayon, gomme, couleur et épaisseur selon les options du système.

Vous pouvez dessiner avec l’Apple Pencil ou avec le doigt si cette interaction est activée.

Modifier un dessin​

Sélectionnez l’annotation dessinée pour modifier sa position, sa taille, son calque ou ses propriétés. Si le dessin est rééditable, ouvrez-le à nouveau avec les outils PencilKit.

Effacer ou supprimer​

Utilisez la gomme PencilKit pour corriger une partie du dessin, ou supprimez l’annotation complète si elle n’est plus utile.

Comme pour les autres annotations, vérifiez avant suppression qu’elle n’est pas utilisée dans un groupe ou enregistrée comme modèle dans la bibliothèque.
