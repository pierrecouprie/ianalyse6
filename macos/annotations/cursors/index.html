Utiliser les curseurs

Les curseurs sont des annotations un peu particulières : ils se présentent sous la forme de graphiques animés en fonction d'images-clés. Ils servent à créer des têtes de lecture qui se déplacent sur une partition au rythme de la musique, ou des annotations qui mettent en valeur l'enchaînement de plusieurs notes ou accords.

Les curseurs ne peuvent être créés que dans les Documents de type diaporama.

Il existe quatre types de curseurs :

  • : à défilement horizontal.
  • : à défilement vertical.
  • : à défilement circulaire.
  • : à défilement en suivant une ligne.

Vous pouvez ajouter plusieurs curseurs sur chaque diapositive.

Il existe deux techniques pour ajouter des curseurs :

  • Manuel : vous réglez chaque image-clé manuellement. C'est idéal pour créer une tête de lecture sur une partition un peu complexe ou qui présente des variations de tempo.
  • Rapide : vous réglez la synchronisation temporelle pendant la lecture. Cette technique est idéale pour des partitions à un tempo modéré dans lesquelles il n'y a pas de variations de tempo.

Ajouter un curseur manuel​

  • Positionnez la tête de lecture sur le début du curseur.
  • Cliquez sur le bouton de la barre d'outils et sélectionnez Ajouter un curseur manuel.
  • Dans la fenêtre qui s'ouvre, choisissez les propriétés du curseur :
    • Son Type.
    • Sa Forme. Toutes les formes ne sont pas disponibles pour tous les types.
    • Le nombre d'Images-clés : il sera possible d'en ajouter ou d'en supprimer ensuite. Ce nombre contient la première et la dernière image-clé positionnées aux extrémités du curseur.
    • Si la position de la forme doit être Interpolée entre les images-clés.
    • La Couleur.
  • Cliquez sur Ajouter.

Ajouter un curseur rapide​

  • Positionnez la tête de lecture sur le début du curseur.
  • Cliquez sur le bouton de la barre d'outils et sélectionnez Ajouter un curseur rapide.
  • Le panneau de droite s'ouvre et permet de gérer les étapes :
    • Étape 1 : marquer les positions temporelles. En déplaçant le curseur sur la vue principale, vous pouvez cliquer pour positionner les images-clés, par exemple sur les temps de la partition insérée en fond de diapositive.
    • Vous pouvez modifier la Taille et la Couleur du curseur avec le panneau de droite.
    • Étape 2 : cliquez sur Positions temporelles dans le panneau de droite.
    • Lancez la lecture et cliquez sur la vue principale pour associer une position temporelle à chaque position graphique.
    • Étape 3 : cliquez sur Finaliser dans le panneau de droite.
    • Le curseur est créé sur la vue principale.

Modifier le curseur​

Sélectionnez le curseur et ouvrez l'inspecteur avec le bouton de la barre d'outils pour afficher ses propriétés.

Les propriétés spécifiques du curseur se trouvent dans l'onglet :

  • Modifiez la Forme. Toutes les formes ne sont pas disponibles pour tous les types.
  • Modifiez la Direction pour la forme triangulaire.
  • Activez ou non l'Interpolation des images-clés.
  • Animation d'image-clé : appliquez l'animation des annotations à chaque image-clé.
  • Lissage : lisse la ligne pour les curseurs de type .
  • Largeur de certains types de curseur.
  • Taille de certains types de curseur.
  • Taille du centre des curseurs de type .
  • Chemin : uniquement pour les types :
    • Visible : afficher la ligne suivie par le curseur.
    • Masquer la forme.
    • Taille de la forme.
  • Img. sélectionnée : il s'agit de l'image-clé actuellement affichée sur la vue principale :
    • Dernière img. : afficher les propriétés de la dernière image-clé.
    • Interpolation : interpoler avec l'image-clé suivante.
    • Position entre 0.0 et 1.0.
    • Temps.
    • Couleur.
    • Opacité.

Supprimer un curseur​

Sélectionnez le curseur et utilisez la touche ou le menu Edition > Supprimer.
