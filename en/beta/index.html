Install the beta version

Try iAnalyse 6 before its release and help improve it through TestFlight, Apple’s beta testing app.

Testing currently covers macOS. The iPadOS version will follow later.

Before you begin​

  • Use a Mac running macOS 13 or later that meets the requirements of the version offered in TestFlight.
  • Back up your projects and work on copies: the beta may still contain bugs.
  • You can import iAnalyse 5 projects into iAnalyse 6, but iAnalyse 6 projects cannot be opened in iAnalyse 5.

If you want to keep version 5 of iAnalyse, simply rename it—for example, to "iAnalyse 5."

Install in three steps​

  1. Install TestFlight from the Mac App Store.
  2. Open the beta invitation link on your Mac and accept the invitation.
  3. In TestFlight, click Install for iAnalyse 6, then Open.

The invitation link: https://testflight.apple.com/join/jsqtAfKQ

Start testing​

Begin with a simple project: import a media file, add a few annotations, then save and reopen the project. Next, try your usual workflows.

Read What to Test in TestFlight for the points to check in each new version. Difficulties using the interface are just as useful to report as bugs.

Report a problem​

In TestFlight, select iAnalyse 6, then Send Beta Feedback. Describe what you did and what went wrong; a screenshot may help.

What should I include in my feedback?

Include the iAnalyse version and build number, your Mac model and macOS version. Describe the steps, the expected result and the actual result. Mention whether the problem occurs repeatedly.

If the app closes unexpectedly, submit the report offered and describe what you were doing just before the crash. Do not attach confidential documents or media you are not allowed to share.

Frequently asked questions​

TestFlight asks for a code. What should I do?

Follow the instructions in your invitation email. You do not need to create a code yourself. If you have a public invitation link, open it on the Mac you will use for testing.

How do I install updates?

Open TestFlight and install the new version when available. You can also enable automatic updates on the iAnalyse 6 app page in TestFlight.

The beta has expired. Can I continue testing?

Each TestFlight build can be used for up to 90 days after it is uploaded to Apple. TestFlight shows the remaining time. After expiry, install a newer build when one is available to continue testing.

Can I use an older Mac or an iPad?

Testing macOS apps through TestFlight requires macOS 13 or later. The final version of iAnalyse 6 is planned to support macOS 12 or later. iAnalyse 5 remains available for older Macs.

The iPadOS beta will be offered later; this page will be updated when it becomes available.
