The interface

The iAnalyse interface is organized around a single window allowing you to navigate between imported files and created Documents.

Parts of the interface​

The interface is organized into 5 parts:

  1. The toolbar groups together playback, editing and display commands.
  2. The browser provides access to imported files and Project Documents.
  3. The main view allows you to view files and modify Documents.
  4. The timeline displays the time position, the media selected for playback, and any elements with time properties.
  5. The Property inspector displays the settings for the selected item.

The toolbar​

The toolbar includes commands for the main actions:

  • shows or hides the browser.
  • and control playback when a media file or Document is selected in the browser.
  • The counter displays the time position and the media file activated for playback.
  • shows advanced playback controls.
  • allows you to add graphic elements like slides, markers, filters, etc.
  • opens the annotation library.
  • displays all annotations independently of their temporal animations.
  • shows or hides the Documents timeline.
  • shows or hides the Property inspector.

The browser​

The browser displays all imported files, Documents and tools created.

It allows you to select the elements to display in the main view.

The main view​

This is the space for graphical editing and display of multimedia visualizations.

The timeline​

The timeline displays the playback progress and the temporal position of the graphic elements: annotations, markers, segmentations, etc.

The Property inspector​

The inspector displays the properties of the selected item in the main view or timeline.
