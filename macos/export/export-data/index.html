Exporter les données

L’export de données permet de récupérer des éléments du Projet dans un format utilisable ailleurs. Il est utile pour archiver une analyse, comparer des résultats ou poursuivre le travail dans un autre logiciel.

Choisir les éléments à exporter​

Ouvrez la commande d’export de données, puis choisissez la source à exporter. Selon le Projet, il peut s’agir de données d’analyse, d’éléments graphiques ou d’informations structurées.

Vérifiez toujours que les éléments sélectionnés correspondent bien à ce que vous voulez réutiliser.

Choisir le format​

Les formats disponibles peuvent inclure TXT, XML ou JSON. Choisissez le format selon le logiciel dans lequel les données seront utilisées.

  • TXT est pratique pour une lecture simple ou un tableur ;
  • XML conserve une structure descriptive ;
  • JSON convient bien aux traitements informatiques ou aux échanges structurés.

Vérifier le fichier exporté​

Après export, ouvrez le fichier dans l’application cible ou dans un éditeur de texte pour vérifier son contenu. Cette vérification évite de découvrir trop tard qu’une mauvaise source ou un mauvais format a été choisi.
