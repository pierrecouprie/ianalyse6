Use Graphical Representations

Graphical representations let you visualize the Project’s media and data. They transform an audio, video, musical, or numerical file into a readable form over time.

Add a Representation​

Open the Document where you want to display the representation, then add a representation from the inspector or dedicated command.

The menu only offers representations compatible with the files available in the Project. If an expected representation does not appear, check that the source file has been imported.

Choose the Source File​

Each representation uses a source file: audio or video media, data file, musical file, or computation result.

After choosing the representation type, select the file to display. If several files are available, name them clearly in the Project to avoid confusion.

Available Representation Types​

Available representations can include:

  • waveform, to visualize the amplitude of an audio or video media file;
  • sonogram, to visualize frequency evolution;
  • graph, to display data series;
  • gradient, to represent values as colors;
  • complex, to combine several data dimensions;
  • fundamental frequency, to display an estimate or pitch data;
  • distance matrix, to visualize relationships or similarities;
  • chromagram, to represent energy by pitch classes;
  • MFCCs, to display coefficients from audio analysis;
  • piano roll, to represent musical data over time.

Edit Appearance​

Select the representation to display its properties. Depending on the selected type, you can adjust opacity, colors, vertical scale, visible series, filters, or display settings.

Settings should support the readability of the analysis. Avoid stacking too many representations if they make the Document difficult to understand.

Work with Several Representations​

Several representations can be used in the same Project to compare different analysis levels. For example, you can combine a waveform, a sonogram, and a fundamental frequency curve.

When several representations are displayed, use layers, opacity, and colors to keep the reading clear.
