Manage Imported Files

Imported files are the sources used by the Project’s Documents, annotations, and representations. It is important to keep them accessible throughout the analysis.

Display Project Files​

The navigator displays the files available in the Project. Select a file to view its information or to use it in a Document.

A single Project can contain several file types: audio, video, image, PDF, MIDI, MusicXML, MEI, or data.

Delete a File​

A file can only be deleted if it is no longer used in the Project. If the delete button or command is not available, it usually means that a Document, annotation, or representation still uses this file.

Before deleting a file, check that it is no longer needed for the analysis. Final deletion may occur the next time the Project is saved.

Replace or Locate Media​

If a media file cannot be found, iAnalyse may ask you to locate it. Select the corresponding file at its new location.

When you replace media, then check the timeline, annotations, and representations that use it. If the duration or content of the new file differs from the old one, some time-based elements may need to be adjusted.

Linked Files and Copied Files​

On iPadOS, the Project strategy directly influences how audio and video files are stored.

A copied file makes the Project more self-contained. A linked file keeps the Project size smaller, but it must remain available at its original location.
