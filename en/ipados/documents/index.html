Use Documents

Document types​

With iAnalyse, you work from imported files by creating Documents. There are 4 types of Documents:

  • Slideshow, to prepare a simple presentation, annotate a score or any other use in which you need several pages.
  • Representation, to work with temporal or graphic visualizations.
  • Video, to work with video media.
  • Canvas, to freely organize objects and annotations on a view.

On iPadOS, Documents follow the same principles as on macOS. The main differences are access to properties in the left sidebar and touch interactions in the main view.

Create a Document​

To create a Document, first select an audiovisual or music file (MIDI, MusicXML, or MEI). Use the add button or the creation menu, then choose one of the available Document types.

Video Documents can only be created from a file with a video track.

The structure of a Document​

Documents include 2 elements:

  • The editing view, which occupies the largest area: it is the view which will be exported, for example as an image or video.
  • The timeline under the editing view: it displays the temporal properties of the elements selected in the editing view.

Grid properties​

The grid appears on the editing view. Depending on the Documents, it can take several forms.

The ordinary grid​

The regular grid is present in Slideshow, Video and Canvas Documents. It is managed by 5 properties:

  • Visibility.
  • Magnetism for annotations.
  • Mode: grid or points.
  • The spacing determines the size of the grid.
  • Divisions determines the number of subdivisions of the grid.

The representation grid​

In the representations, the grid and the vertical rulerr are combined and the properties are distributed over two panels.

The representation properties inspector provides access to general properties:

  • Display allows you to display the time ruler, vertical rulerr and grid.
  • Target determines the representation that will be used to construct the vertical rulerr and the grid.
  • Mode determines the vertical ruler to use for musical representations (logarithmic spectrogram, fundamental frequency, etc.): frequencies or musical pitches.

To display the vertical rulerr and horizontal grid lines, you must select a representation in the Target property.

The advanced properties panel is displayed by tapping the button.

Advanced properties: grid:

  • Set the display of the vertical and horizontal lines of the grid.
  • Color of the grid.
  • Opacity of the grid.
  • Mode determines the ruler to use for musical representations (logarithmic spectrogram, fundamental frequency, etc.): frequencies or musical pitches.

Advanced properties: pitch graduations:

These controls are only active if a musical representation is selected in Target and Pitch is selected in Mode.

  • A3 Frequency: the reference tuning frequency.
  • Element: the line of the note to edit.
  • Visibility [grid and ruler]: display of the note.
  • Octave [ruler]: display of the octave number.
  • Min. Range and Max. Range [grid and ruler]: allow you to reduce the displayed pitch range.
  • Color [grid and ruler].
  • Line [grid]: thicker or dotted line.

Pitch parameters are only active with representations based on logarithmic frequency visualization or musical pitch extraction.
