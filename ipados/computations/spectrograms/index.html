Calculer des sonagrammes

Un sonagramme représente l’évolution du contenu fréquentiel d’un fichier audio ou vidéo. Il permet d’observer les zones d’énergie, les attaques, les textures et certains comportements harmoniques.

Préparer le calcul​

Importez d’abord un fichier audio ou vidéo. Ouvrez ensuite les fonctions de calcul et choisissez le fichier source à analyser.

Avant de lancer le calcul, vérifiez le nom du fichier de sortie. Un nom clair est important si le Projet contient plusieurs sonagrammes ou plusieurs versions d’un même calcul.

Régler les paramètres FFT​

Les paramètres FFT déterminent la précision de l’analyse. Une fenêtre plus grande améliore la précision fréquentielle, mais réduit la précision temporelle. Une fenêtre plus petite rend les événements temporels plus lisibles, mais donne moins de détail dans les fréquences.

Les valeurs par défaut conviennent à la plupart des usages. Modifiez-les seulement si vous savez ce que vous voulez observer.

Choisir le type de sonagramme​

Les types disponibles peuvent inclure :

  • FFT, pour un sonagramme standard ;
  • FFT stéréo, pour distinguer les informations gauche, droite et centre ;
  • FFT logarithmique, utile pour les sons harmoniques ;
  • chromagramme, pour observer l’énergie par classes de hauteurs ;
  • FFT différentielle, pour mettre en évidence les changements ;
  • MFCCs, pour représenter des caractéristiques utiles à la comparaison de sons.

Vous pouvez calculer plusieurs types si vous souhaitez comparer différentes lectures du même média.

Utiliser le résultat​

Une fois calculé, le sonagramme devient un fichier du Projet. Vous pouvez l’afficher dans la timeline ou dans une représentation graphique compatible.
