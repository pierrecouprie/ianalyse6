Use cursors

Cursors are somewhat special annotations: they appear in the form of animated graphics based on keyframes. They are used to create playheads that move on a score to the rhythm of the music or annotations that highlight the sequence of several notes or chords.

Cursors can only be created in Slideshow Documents.

There are four types of cursors:

  • : horizontal scrolling.
  • : vertical scrolling.
  • : circular scrolling.
  • : scrolling following a line.

You can add multiple cursors to each slide.

There are two techniques for adding cursors:

  • Manual: you adjust each keyframe manually. This is ideal for creating a playhead on a slightly complex score or one that has tempo variations.
  • Easy: you adjust the time synchronization during playback. This technique is ideal for scores at a moderate tempo in which there are no or few tempo variations.

Add a manual cursor​

  • Position the playhead at the moment where the cursor should appear.
  • Click the button on the toolbar and choose Add Manual Cursor.
  • In the window that opens, choose the cursor properties:
    • Its Type.
    • Its Shape. Not all shapes are available for all types.
    • The number of Keyframes: you can add or delete keyframes later. This number includes the first and last keyframes at the ends of the cursor.
    • Whether the position of the shape should be Interpolated between keyframes.
    • The Color.
  • Click Add.

You cannot change the Type of a cursor once it is added.

With the exception of Type, all of these properties can then be edited with the Property inspector.

Add an easy cursor​

  • Position the playhead at the moment where the cursor should appear.
  • Click the button on the toolbar and choose Add Easy Cursor.
  • The right panel opens and allows you to manage the steps:
    • Step 1: mark the graphical positions. By moving the cursor on the main view, you can click to position the keyframes, for example on the beats of the score inserted as the slide background.
      • You can change the cursor's Size and Color in the right panel.
    • Step 2: Click Time-based positions in the right panel.
      • Start playback and click on the main view to associate a time position with each graphic position.
    • Step 3: Click Finalize in the right panel.
      • The cursor is created on the main view.

Edit cursor​

Select the cursor and open the inspector with the toolbar button to display its properties.

Specific cursor properties can be found in the tab:

  • Modify the Shape. Not all shapes are available for all types.
  • Change the Direction of the triangular shape.
  • Enable or disable Interpolation between keyframes.
  • Keyframe Animation: apply annotation animation to each keyframe.
  • Smoothing: smoothes the line for type cursors.
  • Width of certain cursor types.
  • Size of certain cursor types.
  • Center size of type cursors.
  • Path: only for types :
    • Visible: display the line followed by the cursor.
    • Hide shape.
    • Size of the shape.
  • Selected Frame: this is the keyframe currently displayed in the main view:
    • Last Frame: display the properties of the last keyframe.
    • Interpolation: interpolate with the next keyframe.
    • Position between 0.0 and 1.0.
    • Time.
    • Color.
    • Opacity.

Delete a cursor​

Select the cursor and press the key, or choose Edit > Delete.

Add or remove keyframes​

To change a cursor's keyframes:

  • Double-click it; the cursor switches to advanced editing mode.
  • You can change the position of a keyframe in the main view by clicking and dragging the corresponding handle
  • You can add a keyframe by positioning the cursor between 2 keyframes, a handle appears on which you can click.
  • You can delete a keyframe by holding down the Control key, the keyframe handle changes to and you can click to delete it

In the timeline, keyframes appear as vertical lines:

  • Move the pointer near a keyframe to reveal its selection area.
  • Click and drag.

You cannot delete or add keyframes in the timeline; you must do it in the main view.
