Bibliothèque d’annotations

La bibliothèque d’annotations permet de conserver des annotations ou des groupes d’annotations pour les réutiliser dans d’autres Documents ou d’autres Projets.

Ouvrir la bibliothèque​

Ouvrez la bibliothèque depuis la barre d’outils avec le bouton .

Vous pouvez sélectionner :

  • Les dernières annotations utilisées.
  • Les annotations Utilisateur que vous avez importées dans la bibliothèque.
  • Les Médias images ou vidéo importés dans le Projet et que vous pouvez utiliser sous la forme d'annotations.
  • Les différentes catégories d'annotations.

Ajouter une annotation à la bibliothèque​

  • Sélectionnez une annotation sur la vue principale d'un Document.
  • Sélectionnez le menu Edition > Ajouter l'annotation à la bibliothèque de l'utilisateur.
  • L'annotation est ajoutée dans la catégorie Utilisateur de la bibliothèque.
