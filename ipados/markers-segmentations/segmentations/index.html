Créer des segmentations

Une segmentation sert à :

  • Représenter des moments clés.
  • Représenter le retour d'un thème ou d'un instrument dans une musique, d'un personnage ou d'un cadrage dans un film, d'une position dans une interprétation, etc.
  • Représenter les différentes parties d'une structure.
  • Représenter la forme sur plusieurs niveaux.

Afficher la segmentation​

La segmentation est affichée dans la ligne temporelle d'un Document. Pour l'afficher, touchez le bouton de la ligne temporelle. Les cinq couches s'affichent par défaut.

Vous ne pouvez pas ajouter de segmentation dans un fichier audionumérique, les segmentations ne s'ajoutent que dans les Documents.

Lorsque vous créez un Projet, il contient une segmentation par défaut. Cette segmentation peut être affichée dans tous les Documents du Projet. Vous pouvez la modifier ou en créer de nouvelles.

Les segments​

Une segmentation contient des segments qui sont associés à une couche.

Créer un segment​

Pour créer un segment, touchez deux fois la couche cible.

Par défaut, les segments créés n'ont qu'une date de début et durent jusqu'au segment suivant, ou jusqu'à la fin s'il n'y en a pas.

Supprimer un segment​

Sélectionnez le segment et utilisez la touche ou le menu Edition > Supprimer.

Éditer un segment​

Pour déplacer la date de début d'un segment, touchez son début, puis faites glisser la zone de sélection qui apparaît.

Pour éditer les autres propriétés d'un segment :

  • Sélectionnez le segment.
  • Affichez l'inspecteur avec le bouton de la ligne temporelle. Sur iPadOS, il apparaît dans le panneau latéral gauche.
  • Dans l'inspecteur, sélectionnez l'onglet .

Les segments possèdent les propriétés suivantes :

  • Il existe 3 Types de segments :
    • : segment qui ne représente qu'un instant ; il apparaît sous la forme d'un rectangle en dégradé de transparence.
    • : segment qui continue jusqu'au suivant ou jusqu'à la fin s'il n'y en a pas.
    • : segment qui possède un début et une fin spécifique.
  • Les segments sont associés à l'une des Couches de la segmentation.
  • Les segments ont une Étiquette sous la forme d'un texte ou d'un symbole à choisir dans la liste.
  • Les segments ont une Couleur.
  • Les segments ont une date de Début. Elle possède plusieurs propriétés :
    • Le Type peut prendre deux états :
      • si le début commence net.
      • si le début est flou, il est représenté par un dégradé de transparence.
    • La Position temporelle.
    • L'Intervalle de dégradé lors de l'utilisation d'un type .
  • Les segments de type ont une date de Fin. Elle possède plusieurs propriétés :
    • Le Type peut prendre deux états :
      • si la fin s'arrête net.
      • si la fin est floue, elle est représentée par un dégradé de transparence.
    • La Position temporelle de fin.
    • L'Intervalle de dégradé lors de l'utilisation d'un type .

Les segmentations​

Pour éditer les propriétés des segmentations :

  • Affichez l'inspecteur avec le bouton de la ligne temporelle. Sur iPadOS, il apparaît dans le panneau latéral gauche.
  • Dans l'inspecteur, sélectionnez l'onglet .

Gérer les segmentations​

La première section de l'inspecteur de propriétés des segmentations vous permet :

  • Masquer ou afficher la segmentation.
  • Modifier la segmentation.

Le bouton vous permet d'afficher les segmentations disponibles dans le Projet :

  • Touchez deux fois le nom de la segmentation pour le modifier.
  • Sélectionnez pour ajouter une segmentation.
  • Sélectionnez pour supprimer une segmentation.
  • Sélectionnez pour dupliquer une segmentation.

Gérer l'apparence​

Vous pouvez désactiver le magnétisme entre les segments.

Type permet d'afficher une segmentation sous plusieurs formes :

  • Une représentation Linéaire est l'affichage par défaut. Les segments de toutes les couches sont représentés.
  • Un Diagramme formel représente les segments d'une couche en les classant en fonction de leur étiquette (texte ou symbole).
  • Un Diagramme en arc permet de visualiser les motifs qui se répètent dans les segments d'une couche.
  • Une Matrice de distance
  • Une Matrice de séquence
  • Un Diagramme états-transitions permet de visualiser les enchaînements de segments.

Gérer les couches​

Il y a 3 propriétés :

  • Les modes de Couleurs :
    • : aucune couleur n'est affichée.
    • : la ligne complète est colorée.
    • : une petite bande couleur est dessinée au début de la ligne.
  • Afficher les Lignes horizontales de séparation des couches.
  • Afficher les Étiquettes en début de ligne.

Gérer les segments​

  • Afficher les Étiquettes des segments.
  • Modifier la Taille des étiquettes.
  • Modes de Couleurs :
    • Identique : même couleur.
    • Couleur de la Couche.
    • Alterné entre 2 couleurs.
    • En fonction de l'Étiquette du segment.
    • En fonction de la Durée du segment.
  • Opacité des segments.
