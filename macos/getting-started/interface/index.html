L’interface

L'interface d'iAnalyse est organisée autour d'une seule fenêtre permettant de naviguer entre les fichiers importés et les Documents créés.

Les zones principales​

Un Projet ouvert comporte généralement les zones suivantes :

  • le navigateur, qui donne accès aux fichiers importés et aux Documents du Projet ;
  • la vue principale du Document, où vous visualisez les fichiers et modifiez les Documents ;
  • la ligne temporelle, qui affiche la position temporelle, le média sélectionné pour la lecture et tous les éléments ayant des propriétés temporelles ;
  • l’inspecteur de propriétés, qui affiche les réglages de l’élément sélectionné ;
  • la barre d’outils, qui regroupe les commandes de lecture, d'édition et d’affichage. On retrouve aussi ses fonctions dans les menus.

Utiliser le navigateur​

Le navigateur sert à passer d’un élément du Projet à un autre. Vous pouvez y sélectionner un fichier importé ou ouvrir un Document.

Lorsque vous sélectionnez un élément, le contenu affiché dans la vue principale et dans l’inspecteur change selon le contexte.

Utiliser la vue principale​

La vue principale est l’espace de visualisation des fichiers et de travail des Documents. C'est l'espace qui peut être exporté en image, vidéo, etc.

La vue principale est synchronisée avec la ligne temporelle lorsque le Document contient des éléments avec des propriétés temporelles.

Utiliser l’inspecteur de propriétés​

L’inspecteur affiche les propriétés de l’élément sélectionné. Selon le type d’élément, vous pouvez visualiser les propriétés ou les modifier.
