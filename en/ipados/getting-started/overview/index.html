iAnalyse for iPadOS Overview

iAnalyse is a workspace for audiovisual documents. It lets you bring audio, video, image, PDF, and data files together in a single Project, then create Documents to visualize, analyze, annotate, and present them.

Understand How a Project Is Organized​

In iAnalyse, the main file is called a Project. A Project can contain two types of items:

  • Files, such as audio and video media, images, PDFs, MIDI, MusicXML, MEI, or data files.
  • Documents, which are the workspaces where you analyze and organize files.

A Project can contain several Documents. The available Document types are:

  • Slideshow, for preparing a simple presentation, annotating a score, or any other use that requires multiple pages.
  • Representation, for working with time-based or graphical visualizations of an audio signal.
  • Video, for working with video media.
  • Canvas, for freely arranging objects and annotations in a view.

On iPadOS, each Project also has a Project strategy. It determines how iAnalyse stores audio and video files to achieve the right balance of size, quality, and portability. See Project Strategy for details.

Work with the Timeline​

The timeline contains a visualization of the media loaded in the audiovisual player. It also lets you view and edit the time properties of items selected in the main view, as well as segmentations.

Annotate and Visualize​

Annotations are graphical items you add to a Document to comment on, show, compare, or structure your analysis. They can contain text, graphics, or visual content.

Representations display audio, MIDI, and data files in different forms: waveform, spectrogram, graph, chromagram, MFCCs, piano roll, or matrix.

iPadOS-Specific Features​

The overall structure is shared by both platforms. However, two differences are important:

  • The Project browser and Property inspector are grouped in the left sidebar.
  • On iPadOS, drawing uses PencilKit and Apple Pencil, while macOS uses simpler mouse-based drawing. Drawings made on iPad appear as images when the Project is opened on macOS.
