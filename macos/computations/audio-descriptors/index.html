Calculer des descripteurs audio

Ce document décrit les descripteurs audio calculés par iAnalyse. Les formules utilisent les notations suivantes :

SymboleSignification
x[n]Echantillon temporel dans la fenetre d'analyse
NTaille de la fenetre
X[k]Magnitude lineaire du bin FFT k
f_kFrequence centrale du bin k, entre 0 et Nyquist
L[n], R[n]Echantillons des canaux gauche et droit
epsPetite constante evitant log(0) ou une division instable

Pipeline general​

Les fichiers audio sont convertis dans le pipeline d'analyse courant, puis les descripteurs sont calcules par fenetres. Les descripteurs temporels utilisent directement le signal de la fenetre, les descripteurs spectraux utilisent une FFT dediee qui retourne des magnitudes lineaires, distincte de la FFT d'affichage du sonogramme. Les descripteurs differentiels comparent la fenetre courante a la fenetre precedente.

Pipeline type :

Audio -> resampling 44100 Hz -> decoupage en fenetres -> fenetre d'analyse -> FFT magnitudes lineaires -> descripteurs spectraux

Pour les descripteurs stereo :

Audio stereo -> extraction des deux premiers canaux -> decoupage synchronise -> calcul L/R ou MID/SIDE

Les graphes de donnees d'iAnalyse utilisent une echelle d'affichage simplifiee. Certains descripteurs sont naturellement dans 0...1, d'autres utilisent un maxRange ou un minRange pour etre affiches.

Peak Frequency​

Fonctionnement​

Peak Frequency cherche le bin spectral de magnitude maximale et retourne sa frequence centrale. Il represente donc la frequence dominante de la fenetre, sans interpolation sous-bin ni estimation perceptive de hauteur.

Formule​

k_{max} = \arg\max_k X[k]
F_{peak} = f_{k_{max}}

Pipeline​

Signal mono -> fenetre d'analyse -> FFT magnitudes lineaires -> recherche du maximum -> frequence du bin

Utilisation en analyse musicale​

Il est utile pour suivre une frequence dominante, une resonance, une fondamentale tres presente ou un pic spectral stable. Il est moins fiable pour les textures bruitées, les accords denses ou les sons dont la fondamentale n'est pas le pic le plus fort.

RMS Amplitude​

Fonctionnement​

RMS Amplitude mesure l'energie moyenne du signal dans la fenetre. Contrairement a une amplitude de crete, le RMS represente mieux la puissance moyenne locale.

Formule​

RMS = \sqrt{\frac{1}{N}\sum_{n=0}^{N-1}x[n]^2}

Pipeline​

Signal mono -> fenetre temporelle -> carre des echantillons -> moyenne -> racine carree

Utilisation en analyse musicale​

Il permet de suivre la dynamique, les crescendos, les ruptures d'energie et les zones de silence relatif. Il sert aussi de base a d'autres mesures comme Loudness ou Onset Strength.

Spectral Centroid​

Fonctionnement​

Spectral Centroid calcule le centre de gravite frequentiel du spectre. Plus la valeur est haute, plus l'energie est concentree dans les frequences elevees.

Formule​

C = \frac{\sum_k f_k X[k]}{\sum_k X[k]}

Pipeline​

Signal mono -> fenetre d'analyse -> FFT magnitudes lineaires -> ponderation par frequence -> moyenne ponderee

Utilisation en analyse musicale​

Il est tres utile pour suivre la brillance, les filtrages, les changements de timbre et l'evolution globale du spectre. Dans la musique electroacoustique, il peut bien marquer les passages entre sons sombres et sons brillants.

Spectral Crest​

Fonctionnement​

Spectral Crest mesure le rapport entre le maximum spectral et la moyenne du spectre. Le calcul ignore le bin DC pour eviter que l'energie continue ou tres basse frequence biaise le resultat.

Formule​

SC = \frac{\max_{k>0} X[k]}{\frac{1}{K-1}\sum_{k=1}^{K-1}X[k]}

Pipeline​

Signal mono -> fenetre d'analyse -> FFT magnitudes lineaires -> suppression DC -> maximum / moyenne

Utilisation en analyse musicale​

Il permet de distinguer un spectre avec un pic dominant d'un spectre plus reparti. Il est utile pour differencier sons toniques, resonances et masses spectrales plus diffuses.

Spectral Decrease​

Fonctionnement​

Spectral Decrease mesure la pente generale de decroissance des magnitudes spectrales par rapport au premier bin. Une valeur marquee indique que l'energie baisse fortement avec la frequence.

Formule​

SD = \frac{\sum_{k=1}^{K-1}\frac{X[k]-X[0]}{k}}{\sum_{k=1}^{K-1}X[k]}

Pipeline​

Signal mono -> fenetre d'analyse -> FFT magnitudes lineaires -> comparaison au premier bin -> normalisation par energie hors DC

Utilisation en analyse musicale​

Il peut aider a identifier des spectres sombres, amortis ou fortement concentres dans le grave. Il est aussi pertinent pour observer l'evolution d'un filtrage passe-bas ou d'une extinction spectrale.

Spectral Flatness​

Fonctionnement​

Spectral Flatness compare la moyenne geometrique et la moyenne arithmetique du spectre. Une valeur proche de 1 indique un spectre plat et bruité, une valeur proche de 0 indique un spectre plus tonal ou pique.

Formule​

SF = \frac{\exp\left(\frac{1}{K}\sum_k \log(X[k] + \epsilon)\right)}
{\frac{1}{K}\sum_k X[k]}

Pipeline​

Signal mono -> fenetre d'analyse -> FFT magnitudes lineaires -> moyenne geometrique / moyenne arithmetique

Utilisation en analyse musicale​

Il est utile pour separer des sons bruités, souffles ou granulaires de sons harmoniques ou resonants. Il peut aussi contribuer a une aide a la segmentation par type de texture.

Spectral Flux​

Fonctionnement​

Spectral Flux mesure la distance entre deux spectres consecutifs. Il prend en compte les hausses et les baisses d'energie spectrale.

Formule​

Flux_t = \sqrt{\sum_k (X_t[k] - X_{t-1}[k])^2}

Pipeline​

Fenetre precedente et fenetre courante -> FFT magnitudes lineaires -> difference bin a bin -> norme euclidienne

Utilisation en analyse musicale​

Il est utile pour detecter les changements spectraux, les ruptures de texture, les transitions et certains debuts d'evenements. Il est souvent pertinent pour une future interface d'aide a la segmentation.

Spectral Rolloff​

Fonctionnement​

Spectral Rolloff cherche la frequence sous laquelle se trouve un pourcentage donne de l'energie spectrale cumulee. Le seuil courant vient des reglages, souvent autour de 85 ou 90 pour cent.

Formule​

R = f_m \quad \text{tel que} \quad \sum_{k=0}^{m} X[k] \geq p \sum_{k=0}^{K-1} X[k]

Pipeline​

Signal mono -> fenetre d'analyse -> FFT magnitudes lineaires -> somme cumulee -> frequence au seuil

Utilisation en analyse musicale​

Il donne une indication de l'etendue spectrale effective. Il est utile pour suivre l'ouverture d'un spectre, les filtrages, la brillance et les passages entre sons graves et sons riches en aigus.

Spectral Standard Deviation​

Fonctionnement​

Spectral Standard Deviation mesure la dispersion frequentielle autour du centroide spectral. Il correspond a la racine carree de la variance spectrale.

Formule​

\sigma = \sqrt{\frac{\sum_k (f_k - C)^2 X[k]}{\sum_k X[k]}}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> centroide spectral -> variance ponderee -> racine carree

Utilisation en analyse musicale​

Il aide a distinguer des spectres concentres de spectres etales. Il peut mettre en evidence des changements de largeur spectrale independamment du niveau global.

Spectral Variance​

Fonctionnement​

Spectral Variance mesure la dispersion quadratique du spectre autour du centroide. Une valeur elevee indique que l'energie est repartie loin du centre spectral.

Formule​

\sigma^2 = \frac{\sum_k (f_k - C)^2 X[k]}{\sum_k X[k]}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> centroide spectral -> dispersion quadratique ponderee

Utilisation en analyse musicale​

Il sert a observer la largeur globale du spectre. Il peut etre utile pour comparer des sons etroits, comme des sifflements ou resonances, a des sons plus larges ou bruités.

Zero Crossing Rate​

Fonctionnement​

Zero Crossing Rate compte les changements de signe dans la fenetre temporelle. Le resultat est normalise par le nombre de transitions possibles.

Formule​

ZCR = \frac{1}{2(N-1)}\sum_{n=1}^{N-1} |\operatorname{sgn}(x[n]) - \operatorname{sgn}(x[n-1])|

Pipeline​

Signal mono -> fenetre temporelle -> signes successifs -> comptage des passages par zero

Utilisation en analyse musicale​

Il est sensible aux hautes frequences, aux textures bruitées et aux signaux instables. Il peut aider a distinguer sons graves et stables de sons bruités ou tres riches en aigus.

Average Deviation​

Fonctionnement​

Average Deviation mesure l'ecart moyen absolu des echantillons a leur moyenne. Dans iAnalyse, il est calcule sur le signal temporel.

Formule​

AD = \frac{1}{N}\sum_{n=0}^{N-1}|x[n] - \mu|
\mu = \frac{1}{N}\sum_{n=0}^{N-1}x[n]

Pipeline​

Signal mono -> fenetre temporelle -> moyenne -> ecart absolu moyen

Utilisation en analyse musicale​

Il donne une indication simple de la variabilite d'amplitude dans une fenetre. Il peut completer le RMS pour distinguer des fenetres regulieres de fenetres plus fluctuantes, mais il n'a pas ete aligne avec la sortie LibXtract/Sonic Visualiser.

Inharmonicity​

Fonctionnement​

Inharmonicity estime l'ecart du spectre aux multiples d'une fondamentale approximative. La fondamentale est estimee par le bin spectral le plus fort hors DC, puis chaque bin contribue selon son ecart au multiple harmonique le plus proche, pondere par l'amplitude au carre.

Formule​

h_k = \left\lfloor \frac{f_k}{f_0} + 0.5 \right\rfloor
I = \frac{2 \sum_{k>0}|f_k - h_k f_0| X[k]^2}
{f_0 \sum_{k>0} X[k]^2}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> estimation f0 par pic maximal -> ecart aux harmoniques -> moyenne ponderee

Utilisation en analyse musicale​

Il permet d'observer le degre d'inharmonicite d'un son. Il est pertinent pour distinguer sons harmoniques, sons de cloches, percussions metalliques, textures complexes et transformations de timbre.

Spectral Kurtosis​

Fonctionnement​

Spectral Kurtosis mesure la concentration ou le caractere pointe de la distribution spectrale autour du centroide. Une valeur elevee indique une distribution avec des pics ou des queues marquees.

Formule​

Kurt = \frac{\frac{\sum_k (f_k - C)^4 X[k]}{\sum_k X[k]}}{\sigma^4}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> centroide -> variance -> moment d'ordre 4 normalise

Utilisation en analyse musicale​

Il est utile pour caracteriser des spectres tres concentres, des resonances ou des sons avec quelques composantes dominantes. Il peut completer la variance et le crest pour decrire la forme du spectre.

Loudness​

Fonctionnement​

Loudness est une approximation perceptive simple basee sur le RMS. Elle applique une compression par puissance pour rapprocher la mesure d'une sensation de niveau.

Formule​

Loudness = RMS^{0.6}

Pipeline​

Signal mono -> fenetre temporelle -> RMS -> compression par puissance

Utilisation en analyse musicale​

Il sert a suivre une dynamique percue plutot qu'une energie strictement lineaire. Il peut etre utile pour visualiser des evolutions d'intensite ou des contrastes dynamiques.

Noisiness​

Fonctionnement​

Noisiness est un proxy derive du Harmonic Ratio. Plus le signal est peu periodique, plus la noisiness augmente.

Formule​

Noisiness = 1 - HarmonicRatio

Pipeline​

Signal mono -> fenetre temporelle -> harmonic ratio par autocorrelation -> complement a 1

Utilisation en analyse musicale​

Il peut aider a suivre la part bruitée ou instable d'un signal. Il est utile pour distinguer des textures bruitées de sons periodiques, mais reste un proxy experimental.

Spectral Skewness​

Fonctionnement​

Spectral Skewness mesure l'asymetrie de la distribution spectrale autour du centroide. Une valeur positive indique une distribution plutot tiree vers les hautes frequences, une valeur negative vers les basses frequences.

Formule​

Skew = \frac{\frac{\sum_k (f_k - C)^3 X[k]}{\sum_k X[k]}}{\sigma^3}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> centroide -> ecart-type -> moment d'ordre 3 normalise

Utilisation en analyse musicale​

Il aide a comprendre de quel cote du centroide l'energie spectrale est etiree. Il peut etre utile pour observer des bascules de timbre ou des filtrages asymetriques.

Spectral Sharpness​

Fonctionnement​

Spectral Sharpness estime la brillance perceptive en ponderant davantage les hautes frequences. La version actuelle est une approximation directe sur les bins FFT et non une vraie decomposition psychoacoustique Bark.

Formule​

Sharpness = \frac{\sum_k X[k] \cdot F_k \cdot w(F_k)}
{\sum_k X[k]}
F_k = \frac{f_k}{1000}
w(F_k) =
\begin{cases}
1 & \text{si } F_k \leq 1 \\
F_k & \text{sinon}
\end{cases}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> conversion frequence en kHz -> ponderation hautes frequences -> moyenne ponderee

Utilisation en analyse musicale​

Il permet de suivre la brillance, les attaques riches en aigus, les filtrages et les changements de couleur. Il est particulierement utile pour des sons dont la perception depend fortement de l'energie haute frequence.

Spectral Slope​

Fonctionnement​

Spectral Slope estime la pente lineaire du spectre sur un axe frequentiel normalise entre 0 et 1. Le resultat est ajuste pour rester lisible dans l'affichage des donnees.

Formule​

u_k = \frac{k}{K-1}
Slope =
K \cdot
\frac{K\sum_k u_k X[k] - \sum_k u_k \sum_k X[k]}
{\sum_k X[k]\left(K\sum_k u_k^2 - \left(\sum_k u_k\right)^2\right)}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> axe frequentiel normalise -> regression lineaire normalisee

Utilisation en analyse musicale​

Il permet d'observer si le spectre penche plutot vers les basses ou les hautes frequences. Il peut marquer des filtrages, des changements de densite spectrale ou des pics importants de brillance.

Spectral Smoothness​

Fonctionnement​

Spectral Smoothness mesure l'irregularite locale du spectre en comparant chaque bin a la moyenne logarithmique de ses voisins. Une valeur faible indique un spectre localement regulier.

Formule​

Smoothness =
\frac{1}{K-2}
\sum_{k=1}^{K-2}
\left|
\log(X[k]+\epsilon)
- \frac{\log(X[k-1]+\epsilon)+\log(X[k+1]+\epsilon)}{2}
\right|

Pipeline​

Signal mono -> FFT magnitudes lineaires -> log magnitudes -> comparaison locale aux voisins -> moyenne absolue

Utilisation en analyse musicale​

Il est utile pour suivre la regularite ou l'accident du spectre. Il peut aider a distinguer spectres lisses, bruités, granuleux ou fortement resonants.

Spectral Contrast​

Fonctionnement​

Spectral Contrast divise le spectre en bandes logarithmiques et mesure, dans chaque bande, l'ecart relatif entre la valeur la plus forte et la plus faible. Le resultat est la moyenne des contrastes de bandes.

Formule​

Contrast_b = \frac{Peak_b - Valley_b}{Peak_b + Valley_b + \epsilon}
Contrast = \frac{1}{B}\sum_b Contrast_b

Pipeline​

Signal mono -> FFT magnitudes lineaires -> bandes logarithmiques -> peak/valley par bande -> moyenne

Utilisation en analyse musicale​

Il peut decrire la clarte ou le contraste interne d'un spectre. En analyse musicale, il peut aider a reperer des changements de texture, de densite ou de separation entre composantes.

Spectral Reflux​

Fonctionnement​

Spectral Reflux mesure uniquement les augmentations de magnitude entre deux spectres consecutifs. Les baisses d'energie sont ignorees.

Formule​

Reflux_t = \sqrt{\sum_k \max(X_t[k] - X_{t-1}[k], 0)^2}

Pipeline​

Fenetre precedente et courante -> FFT magnitudes lineaires -> difference positive bin a bin -> norme euclidienne

Utilisation en analyse musicale​

Il est utile pour reperer les apparitions spectrales, les attaques, les entrees de composantes ou les enrichissements brusques du spectre. Il peut completer Spectral Flux dans une interface de segmentation.

Spectral Entropy​

Fonctionnement​

Spectral Entropy transforme les magnitudes en distribution de probabilite puis calcule l'entropie de Shannon normalisee. Une valeur haute indique une energie repartie sur beaucoup de bins.

Formule​

p_k = \frac{X[k]}{\sum_j X[j]}
Entropy = -\frac{\sum_k p_k \log_2(p_k)}{\log_2(K)}

Pipeline​

Signal mono -> FFT magnitudes lineaires -> normalisation en probabilites -> entropie de Shannon normalisee

Utilisation en analyse musicale​

Il aide a distinguer spectres concentres, toniques ou resonants de spectres diffus ou bruités. Il est pertinent pour suivre des changements de texture ou de densite.

Harmonic Ratio​

Fonctionnement​

Harmonic Ratio mesure la periodicite du signal par autocorrelation. Il cherche la meilleure correlation normalisee pour des lags correspondant approximativement a des fondamentales entre 50 et 2000 Hz.

Formule​

HR = \max_{\tau \in [\tau_{min}, \tau_{max}]}
\frac{\sum_n x[n]x[n+\tau]}{\sum_n x[n]^2}
\tau_{min} = \frac{sr}{2000}, \quad \tau_{max} = \frac{sr}{50}

Pipeline​

Signal mono -> fenetre temporelle -> autocorrelation normalisee -> maximum dans la plage de lags

Utilisation en analyse musicale​

Il permet de suivre la periodicite ou le caractere tonal d'un son. Il est different d'un ratio odd/even harmonics, qui compare les harmoniques paires et impaires apres estimation des partiels.

Attack Time​

Fonctionnement​

Attack Time mesure, dans chaque fenetre, le temps entre le passage a 10% et 90% du maximum absolu local. Il s'agit d'une version frame-based et non d'une mesure evenementielle basee sur une detection d'onsets.

Formule​

t_{10} = \min\{n : |x[n]| \geq 0.1 \max |x|\}
t_{90} = \min\{n \geq t_{10} : |x[n]| \geq 0.9 \max |x|\}
AttackTime = \frac{t_{90} - t_{10}}{sr}

Pipeline​

Signal mono -> fenetre temporelle -> enveloppe absolue simple -> seuils 10% et 90% -> duree

Utilisation en analyse musicale​

Il peut donner une indication locale de rapidite d'attaque. Pour une analyse plus robuste, une future version pourrait mesurer l'attaque autour d'evenements detectes.

Onset Strength​

Fonctionnement​

Onset Strength mesure l'augmentation positive du RMS entre la fenetre precedente et la fenetre courante. Il s'agit donc d'un onset strength energetique simple.

Formule​

OS_t = \max(RMS_t - RMS_{t-1}, 0)

Pipeline​

Fenetre precedente et courante -> RMS temporel -> difference positive

Utilisation en analyse musicale​

Il peut aider a reperer des attaques ou des augmentations d'energie. Il est plus simple que les methodes spectrales, mais peut rester utile dans une interface de segmentation.

Stereo Balance​

Fonctionnement​

Stereo Balance mesure l'equilibre d'energie entre les deux premiers canaux. La sortie est normalisee pour l'affichage : 0 signifie gauche, 0.5 centre, 1 droite.

Formule​

B_s = \frac{RMS_R - RMS_L}{RMS_R + RMS_L}
StereoBalance = \frac{B_s + 1}{2}

Pipeline​

Canaux gauche/droit -> fenetres synchronisees -> RMS gauche et RMS droit -> balance signee -> normalisation 0...1

Utilisation en analyse musicale​

Il permet de visualiser les deplacements ou desequilibres gauche-droite. Il ne mesure pas la largeur stereo, la correlation ou la phase.

MID/SIDE Ratio​

Fonctionnement​

MID/SIDE Ratio mesure la part d'energie laterale du signal stereo. Une valeur basse indique un signal centre ou mono, une valeur haute indique un signal large ou fortement lateral.

Formule​

Mid[n] = \frac{L[n] + R[n]}{2}
Side[n] = \frac{R[n] - L[n]}{2}
MSRatio = \frac{RMS_{Side}}{RMS_{Mid} + RMS_{Side}}

Pipeline​

Canaux gauche/droit -> transformation MID/SIDE -> RMS mid et side -> ratio side / total

Utilisation en analyse musicale​

Il permet de suivre la largeur stereo, les effets de spatialisation et les passages plus ou moins centres. Il complete Stereo Balance, qui mesure plutot la position gauche-droite.
