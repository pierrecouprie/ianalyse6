Export Data

Data export lets you retrieve Project elements in a format usable elsewhere. It is useful for archiving an analysis, comparing results, or continuing work in another application.

Choose Elements to Export​

Open the data export command, then choose the source to export. Depending on the Project, this can be analysis data, graphical elements, or structured information.

Always check that the selected elements match what you want to reuse.

Choose the Format​

Available formats can include TXT, XML, or JSON. Choose the format according to the application where the data will be used.

  • TXT is convenient for simple reading or a spreadsheet;
  • XML preserves a descriptive structure;
  • JSON is well suited to computational processing or structured exchange.

Check the Exported File​

After export, open the file in the target application or in a text editor to check its content. This avoids discovering too late that the wrong source or format was selected.
