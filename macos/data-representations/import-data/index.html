Importer des données

Les fichiers de données permettent d’ajouter au Projet des valeurs temporelles calculées ou produites par un autre logiciel. Ces données peuvent ensuite être affichées dans des représentations graphiques ou utilisées dans certains calculs.

Importer un fichier de données​

Un fichier de données contient généralement une première colonne de temps, puis une ou plusieurs colonnes de valeurs.

Exemple de structure :

0.000000    0.00
0.011610    2.54
0.023220    6.84
0.034830    0.00

La première colonne indique la position temporelle. Les colonnes suivantes contiennent les valeurs à représenter.

Vérifier l’aperçu avant import​

Avant de valider l’import, vérifiez l’aperçu des données. Contrôlez en particulier :

  • le séparateur de colonnes ;
  • l’unité de temps ;
  • les valeurs minimales et maximales ;
  • le nom donné aux données importées ;
  • le nombre de séries détectées.

Un aperçu incohérent indique souvent un mauvais séparateur, une unité de temps incorrecte ou un fichier mal formaté.

Importer une segmentation​

Vous pouvez importer une segmentation lorsque la structure temporelle a été préparée dans un autre outil. Après l’import, vérifiez les débuts, fins et noms de segments dans la timeline.

Une segmentation importée peut ensuite être modifiée comme une segmentation créée directement dans iAnalyse.

Importer un fichier Scala​

Les fichiers Scala permettent d’ajouter des informations liées aux échelles ou aux hauteurs. Après import, vérifiez que les valeurs correspondent bien au contexte musical du Projet.

Utiliser les données importées​

Une fois importées, les données peuvent être sélectionnées dans les représentations compatibles : graphique, gradient, fréquence fondamentale, matrice, chromagramme ou MFCCs selon le type de fichier.
