Installer la version bêta

Découvrez iAnalyse 6 avant sa sortie et contribuez à son amélioration grâce à TestFlight, l’application de test d’Apple.

Les tests concernent actuellement macOS. La version iPadOS suivra ultérieurement.

Avant de commencer​

  • Utilisez un Mac sous macOS 13 ou une version ultérieure, compatible avec la version proposée dans TestFlight.
  • Sauvegardez vos projets et travaillez sur des copies : la bêta peut encore comporter des erreurs.
  • Vous pouvez importer vos projets iAnalyse 5 dans iAnalyse 6, mais les projets iAnalyse 6 ne peuvent pas être ouverts dans iAnalyse 5.

Installer en trois étapes​

  1. Installez TestFlight depuis le Mac App Store.
  2. Ouvrez le lien d’invitation à la bêta sur votre Mac et acceptez l’invitation.
  3. Dans TestFlight, cliquez sur Installer pour iAnalyse 6, puis sur Ouvrir.

Le lien d’invitation sera ajouté ici dès l’ouverture des tests.

Faire ses premiers essais​

Commencez par un projet simple : importez un média, ajoutez quelques annotations, puis enregistrez et rouvrez le projet. Essayez ensuite vos usages habituels.

Consultez « À tester » dans TestFlight pour connaître les points à vérifier dans chaque nouvelle version. Les difficultés de prise en main sont aussi utiles à signaler que les bugs.

Signaler un problème​

Dans TestFlight, sélectionnez iAnalyse 6, puis Envoyer un commentaire bêta. Décrivez ce que vous avez fait et ce qui ne fonctionne pas ; une capture d’écran peut aider.

Quelles informations inclure dans mon retour ?

Indiquez la version et le numéro de build d’iAnalyse, le modèle de votre Mac et la version de macOS. Décrivez les étapes, le résultat attendu et le résultat observé. Précisez si le problème se répète.

En cas de fermeture inattendue, envoyez le rapport proposé et ajoutez l’action effectuée juste avant. Ne joignez pas de documents confidentiels ni de médias que vous ne pouvez pas partager.

Questions fréquentes​

TestFlight me demande un code : que faire ?

Suivez les instructions de votre e-mail d’invitation. Vous n’avez pas à créer de code vous-même. Si vous disposez d’un lien public, ouvrez-le sur le Mac utilisé pour les tests.

Comment installer les mises à jour ?

Ouvrez TestFlight et installez la nouvelle version disponible. Vous pouvez aussi activer les mises à jour automatiques sur la fiche d’iAnalyse 6 dans TestFlight.

La bêta a expiré : mes tests sont-ils terminés ?

Une version TestFlight est utilisable pendant 90 jours au maximum à compter de son envoi à Apple. La durée restante figure dans TestFlight. Pour continuer après l’expiration, installez une version plus récente lorsqu’elle est disponible.

Puis-je utiliser un Mac plus ancien ou un iPad ?

Les tests macOS via TestFlight nécessitent macOS 13 ou une version ultérieure. La version finale d’iAnalyse 6 est prévue à partir de macOS 12. iAnalyse 5 reste proposée pour les Mac plus anciens.

La bêta iPadOS sera proposée ultérieurement ; cette page sera alors mise à jour.

Pour en savoir plus sur le service : TestFlight — Apple.
