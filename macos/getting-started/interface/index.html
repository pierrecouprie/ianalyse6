L’interface

L'interface d'iAnalyse est organisée autour d'une seule fenêtre permettant de naviguer entre les fichiers importés et les Documents créés.

Les parties de l'interface​

L'interface est organisée en 5 parties :

  1. La barre d’outils, qui regroupe les commandes de lecture, d'édition et d’affichage. On retrouve aussi ses fonctions dans les menus.
  2. Le navigateur, qui donne accès aux fichiers importés et aux Documents du Projet.
  3. La vue principale, où vous visualisez les fichiers et modifiez les Documents.
  4. La ligne temporelle, qui affiche la position temporelle, le média sélectionné pour la lecture et tous les éléments ayant des propriétés temporelles.
  5. L’inspecteur de propriétés, qui affiche les réglages de l’élément sélectionné.

La barre d'outils​

La barre d’outils comprend les commandes des principales actions :

  • affiche ou masque le navigateur.
  • et contrôlent la lecture lorsqu'un fichier multimédia ou un Document est sélectionné dans le navigateur.
  • Le compteur affiche la position temporelle et le fichier multimédia ou le Document sélectionné.
  • affiche les contrôles avancés de lecture.
  • permet d'ajouter des éléments graphiques comme les diapositives, les marqueurs, les filtres, etc.
  • ouvre la bibliothèque d'annotations.
  • affiche toutes les annotations indépendamment de leurs animations temporelles.
  • affiche ou masque la ligne temporelle des Documents.
  • affiche ou masque l'inspecteur de propriétés.

Le navigateur​

Le navigateur affiche tous les fichiers importés, les Documents et les outils créés.

Il permet de sélectionner les éléments à afficher dans la vue principale.

La vue principale​

C'est l'espace d'édition graphique et d'affichage des visualisations multimédias.

La ligne temporelle​

La ligne temporelle affiche le déroulement de la lecture et la position temporelle des éléments graphiques : annotations, marqueurs, segmentations, etc.

L’inspecteur de propriétés​

L’inspecteur affiche les propriétés de l’élément sélectionné dans la vue principale ou la ligne temporelle.
