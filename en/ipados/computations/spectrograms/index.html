Compute Spectrograms

A spectrogram represents the evolution of the frequency content of an audio or video file. It helps you observe energy areas, attacks, textures, and some harmonic behavior.

Prepare the Computation​

First import an audio or video file. Then open the computation functions and choose the source file to analyze.

Before starting the computation, check the output file name. A clear name is important if the Project contains several spectrograms or several versions of the same computation.

Adjust FFT Settings​

FFT settings determine analysis precision. A larger window improves frequency precision but reduces temporal precision. A smaller window makes time events easier to read but gives less frequency detail.

Default values work for most uses. Change them only if you know what you want to observe.

Choose the Spectrogram Type​

Available types can include:

  • FFT, for a standard spectrogram;
  • stereo FFT, to distinguish left, right, and center information;
  • logarithmic FFT, useful for harmonic sounds;
  • chromagram, to observe energy by pitch classes;
  • differential FFT, to highlight changes;
  • MFCCs, to represent features useful for comparing sounds.

You can compute several types if you want to compare different readings of the same media file.

Use the Result​

Once computed, the spectrogram becomes a Project file. You can display it in the timeline or in a compatible graphical representation.
