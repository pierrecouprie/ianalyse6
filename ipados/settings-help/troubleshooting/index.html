Dépannage

Cette page rassemble les problèmes les plus courants et les premiers gestes à essayer avant de modifier profondément un Projet.

Média introuvable​

Si iAnalyse ne trouve plus un média, vérifiez que le fichier n’a pas été déplacé, renommé ou supprimé. Utilisez la commande de localisation proposée pour indiquer son nouvel emplacement.

Si le Projet doit être partagé, privilégiez une stratégie ou un format qui copie les médias nécessaires dans le Projet.

Projet trop volumineux​

Un Projet peut devenir volumineux lorsqu’il contient des vidéos, des médias copiés, des images haute résolution ou de nombreux calculs.

Supprimez les fichiers inutilisés lorsque c’est possible. Sur iPadOS, vérifiez aussi la stratégie de Projet.

Problème d’import​

Si un fichier ne s’importe pas, vérifiez son format, son extension et son contenu. Pour les fichiers de données, contrôlez le séparateur de colonnes, l’unité de temps et la structure des valeurs.

Essayez d’importer un fichier simple pour vérifier si le problème vient du format ou du fichier lui-même.

Problème d’export​

Si un export échoue, testez d’abord une taille plus faible ou un format plus compatible. Les exports vidéo en haute résolution peuvent être longs et demander beaucoup d’espace disque.

Vérifiez aussi que le Projet est sauvegardé et que l’emplacement d’export est accessible.

Compatibilité iAnalyse 5 / iAnalyse 6​

Conservez toujours une copie du projet original avant de l’ouvrir dans iAnalyse 6. Après import, vérifiez les médias, les annotations, les représentations et les segmentations.

Performance sur gros Projets​

Pour améliorer la réactivité, réduisez les éléments affichés simultanément, masquez les calques inutiles, fermez les vues non nécessaires et évitez les représentations trop lourdes pendant l’édition.
