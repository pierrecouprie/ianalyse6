Edit Annotations

An annotation can be edited in the main Document view, in the timeline, and in the properties inspector.

Select an Annotation​

Tap an annotation to select it. The inspector then displays the properties available for this annotation type.

If several annotations overlap, use the timeline or layers to identify the annotation more easily.

Edit Position and Size​

In the main view, you can move the annotation and adjust its size. This visual position determines where the annotation appears in the Document.

In the timeline, you can edit its time position. The start and end determine when the annotation is active.

Edit Content​

Depending on the annotation type, you can edit:

  • the title;
  • text or markdown content;
  • colors;
  • opacity;
  • border;
  • points or shape;
  • associated layer.

Changes are visible immediately in the Document.

Delete an Annotation​

Select the annotation, then use the delete command. Before deleting an important annotation, check that it is not used as a template or in a group.
