Edit annotations

Edit an annotation​

You can edit the properties of an annotation in several ways.

In the main view​

Click the annotation and change its position or size using the selection handles.

If the annotation is a line, you can move it using its handles at both ends.

If the annotation is a polygon or Bézier curve, double-click to edit the points:

  • Click and drag the point handles.
  • Position the cursor between two points and click to add a new point.
  • Hold down the Control key and move the pointer near a point. The handle changes to ; click it to remove the point.

You can also select multiple annotations to move or resize them together:

  • Click outside of annotations and drag to select multiple annotations.
  • Or use the key and click on the annotations to select.
  • Edit the bounding box that contains the selected annotations.

In the timeline​

When an annotation is selected in the main view, a rectangle appears in the timeline:

  • Move the cursor to the start, center or end.
  • Draggable areas appear in the accent color.
  • Click and drag to change temporal properties.

In the Property inspector​

Open the inspector with the button on the toolbar to modify all the properties.

Add animations​

Open the inspector with the toolbar button, then use the tab to edit the annotation animations.

You can add entry, exit, and content animations.

Delete an annotation​

Select the annotation and press the key, or choose Edit > Delete.
