Use Layers

Layers let you organize the annotations of a Document. They are useful for separating several levels of analysis, displaying only certain annotations, or controlling their behavior during playback.

Understand Layers​

Each annotation belongs to a layer. A simple Project may use only one layer, but a more complex Project is often easier to read with several layers.

For example, you can use one layer for general comments, another for musical elements, and another for visual indications.

Create and Rename a Layer​

Add a layer from the layer management area, then give it an explicit name. A short, clear name makes the Project easier to read, especially when several people work on the same analysis.

Place an Annotation in a Layer​

Select the annotation, then choose the desired layer in its properties. The annotation keeps its position and duration, but now follows the settings of the selected layer.

Show, Hide, or Lock a Layer​

You can hide a layer to simplify the display without deleting its annotations. You can also lock a layer to avoid accidentally moving its annotations in the main view.

These commands are useful when the Document contains many overlapping elements.

Define Temporal Behavior​

Layers can control how annotations appear during playback. Depending on the settings, annotations can follow their time range, keep a shared color or opacity, or use a different appearance outside their active duration.

These settings make the analysis easier to read while the media is playing.
