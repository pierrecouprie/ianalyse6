Interface

The iAnalyse interface is organized to keep Project files, the current Document, editing tools, and the timeline together.

Main Areas​

An open Project generally contains the following areas:

  • the navigator, which gives access to imported files and Project Documents;
  • the main Document view, where you see and edit annotations, representations, or slides;
  • the timeline, which displays the time position, playback media, time-based annotations, markers, and segmentations;
  • the properties inspector, which displays the settings of the selected element;
  • the toolbar, which groups playback, add, display, and editing commands.

Using the Navigator​

The navigator lets you quickly move from one Project element to another. You can select an imported file or open a Document.

When you select an element, the content displayed in the main view and in the inspector changes according to the context.

Using the Main View​

The main view is the workspace of the active Document. This is where you place annotations, view representations, edit a canvas, or prepare a slideshow.

The main view is synchronized with the timeline when the Document contains time-based elements.

Using the Properties Inspector​

The inspector displays the properties of the selected element. Depending on the element type, you can edit the title, position, duration, appearance, text content, or representation settings.

If no element is selected, the inspector can display the general properties of the Document or Project.
