Create segmentations

A segmentation is used to:

  • Represent key moments.
  • Represent the return of a theme or an instrument in music, of a character or a framing in a film, of a position in a performance, etc.
  • Represent the different parts of a structure.
  • Represent the musical form on several levels.

You cannot add segmentation to a digital audio file; segmentations are only added to Documents.

Show segmentation​

The segmentation is displayed in the timeline of a Document. To view and edit it, click the button on the timeline. All five layers are displayed by default.

When you create a Project, it contains a segmentation by default. This segmentation can be displayed in all Project Documents. You can modify it or create new ones.

The segmentations are at the project level and not at the Document level. This allows you to display the same segmentation in multiple Documents. You can create as many segmentations as you want.

The segments​

A segmentation contains segments that are associated with a layer.

Create a segment​

To create a segment, simply double-click in the target layer.

By default, created segments only have a start time and last until the next segment or the end of the media.

Delete a segment​

Select the segment and press the key, or choose Edit > Delete.

Edit a segment​

To move the start time of a segment, move the cursor near its start, then click and drag on the selection box that appears.

To edit the other properties of a segment:

  • Select the segment.
  • Show the inspector with the timeline button .
  • In the inspector, select the tab.

Segments have the following properties:

  • There are 3 Types of segments:
    • : segment which only represents an instant; it appears in the form of a rectangle with a transparency gradient.
    • : segment which continues until the next one or until the end if there is none.
    • : segment which has a specific start and end.
  • The segments are associated with one of the Layers of the segmentation.
  • Segments have a Label in the form of text or a symbol to choose from the list.
  • The segments have a Color.
  • Segments have a Start time. It has several properties:
    • The Type can take two states:
      • for a sharp start.
      • for a gradual start, represented by a transparency gradient.
    • The temporal Position.
    • The gradient Interval when using a type.
  • Segments of type have an End time. It has several properties:
    • The Type can take two states:
      • for a sharp end.
      • for a gradual end, represented by a transparency gradient.
    • The end temporal Position.
    • The gradient Interval when using a type.

Segmentations​

To edit the segmentation properties:

  • Show the inspector with the timeline button .
  • In the inspector, select the tab.

Manage segmentations​

The first section of the Segmentations Property inspector allows you to:

  • Hide or show segmentation.
  • Modify the segmentation.

The button allows you to display the segmentations available in the Project:

  • Double-click on the segmentation name to modify it.
  • Select to add segmentation.
  • Select to delete a segmentation.
  • Select to duplicate a segmentation.

Manage appearance​

You can disable snapping between segments.

Type allows you to display a segmentation in several forms:

  • A Linear representation is the default display. Segments from all layers are shown.
  • A Formal Diagram represents the segments of a layer by classifying them according to their label (text or symbol) and by order of appearance.
  • An Arc diagram allows you to visualize the patterns that repeat in the segments of a layer.
  • A Distance Matrix compares each segment with all other segments of the layer. A red box appears when the two segments have the same identity (same title or same symbol). The two axes represent time. The diagonal corresponds to each segment compared to itself and can be hidden with the Hide Identity option.
  • A Sequence Matrix searches for identical consecutive sequences. Each line corresponds to a repeated pattern and the rectangles indicate its different occurrences on the time axis. The pattern size parameter sets the number of consecutive segments to compare, with a minimum of two.
  • A State-transition diagram allows you to visualize the sequences of patterns according to the property Pattern min.

Concerning matrices, for example, with the segmentation A – B – C – A – B – D:

  • The distance matrix connects the two A's and the two B's separately.
  • The sequence matrix detects the repetition of pattern A – B if the Pattern min. is 2.

Manage layers​

There are 3 properties:

  • Color modes:
    • : no color is displayed.
    • : the complete line is colored.
    • : a small color strip is drawn at the start of the line.
  • Show horizontal Lines separating layers.
  • Show Labels at the start of the line.

Manage segments​

  • Show Labels of segments.
  • Change the Size of the labels.
  • Color modes:
    • The color of the Segment.
    • Same: same color.
    • Color of the Layer.
    • Alternate between 2 colors.
    • Depending on the Label of the segment.
    • Depending on the Duration of the segment.
  • Opacity of the segments.
