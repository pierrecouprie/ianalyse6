iAnalyse

iAnalyse est un logiciel d'aide à l'analyse musicale permettant de réaliser des guides d'écoute, d'annoter des documents audiovisuels et MIDI et de produire des représentations de données. iAnalyse se présente comme un espace de travail dans lequel vous importez des fichiers (audio, vidéo, images, PDF, MIDI, etc.) à partir desquels vous créez des visualisations. Dans chaque projet iAnalyse, vous pouvez créer plusieurs documents (diaporamas, représentation du signal, vidéo, partition). Les documents partagent les mêmes fichiers.

iAnalyse fonctionne sur 2 plateformes : macOS et iPadOS. Les projets sont exactement identiques sur les 2 plateformes et sont compatibles avec les 2 systèmes. Les 2 versions contiennent exactement les mêmes fonctionnalités. Leur emplacement est toutefois différents à cause de la différence de fonctionnement de l'interaction.

Configuration minimale​

Cette version de iAnalyse nécessite un système :

  • Sur macOS : 11.0 ou supérieur
  • Sur iPadOS : iOS 16.6 ou supérieur

Sur iPadOS, il est recommander d'avoir suffisamment de mémoire pour stocker les médias ou de travailler sur un cloud.

Pour une utilisation de iAnalyse sur des système macOS plus anciens, télécharger les versions précédentes : https://logiciels.pierrecouprie.fr.
