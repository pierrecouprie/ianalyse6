Import media

Importing adds files to the Project so that they can be played, annotated, represented or used in a Document.

Import an audio or video file​

Importing audio and video files follows the same procedure:

  1. Use the Import > Audio or Video menu.
  2. Select one or more files, then confirm their addition to the Project.
  3. A preview of the file appears in the main view.
  4. If you open the Property inspector, it displays all the file’s properties.

The supported formats are:

  • Audio: WAV, AIFF, MP3, M4A, FLAC.
  • Video: MP4, M4V, MOV.

In preferences, on the Advanced tab, you can select how the audio files are imported:

  • Automatic (default): uncompressed files are imported without modification. Compressed files are converted to AAC at 320 Kbps.
  • Force Compression (AAC): all audio files are compressed to AAC at 320 Kbps when imported.

On iPadOS, the Project strategy also affects audio and video imports. See Project strategy.

Import an image​

Images can be used as visual sources, surfaces for annotations or elements integrated into a Document.

To import an image:

  1. Use the Import > Image menu.
  2. Select one or more files, then confirm their addition to the Project.
  3. A preview of the file appears in the main view.
  4. If you open the Property inspector, it displays all the file’s properties.

The supported formats are:

  • JPG, JPEG, BMP, PNG, TIF, TIFF, HEIF and HEIC.

Images are automatically converted to HEIC format.

Import a PDF​

PDFs are imported as images.

To import a PDF:

  1. Use the Import > PDF menu.
  2. Select one or more files, then confirm their addition to the Project.
  3. A PDF appears as a group of images in the browser.
  4. Each image can be displayed in the main view.
  5. If you open the Property inspector, it displays all the file’s properties.

The PDF pages are saved in HEIC format.

Import music files​

iAnalyse can import MIDI, MusicXML and MEI files. These files are transformed into a format that can be used as media for creating a Document. The audiovisual player uses the internal synthesizer in macOS or iPadOS to play the file.

To import a music file:

  1. Use the Import menu and choose MIDI, MusicXML or MEI.
  2. Select one or more files, then confirm their addition to the Project.
  3. Each file can be displayed in the main view.
  4. If you open the Property inspector, it displays all the file’s properties.

The supported formats are:

  • MID, MIDI, MusicXML, MXL, MEI

Import data​

Data files allow you to add time-based values calculated or produced by other software to the Project. This data can then be displayed in graphical representations or used in certain calculations.

The supported formats are:

  • TXT, CSV

Import a data file​

A data file generally contains a first column of time, then one or more columns of values.

Example structure:

0.000000    0.00
0.011610    2.54
0.023220    6.84
0.034830    0.00

The first column indicates the time position. The following columns contain the values to represent.

Check preview before import​

Before confirming the import, check the data preview. Check in particular:

  • The column separator.
  • The time unit.
  • The minimum and maximum values.
  • The name assigned to the imported data.
  • The number of series detected.

An inconsistent preview often indicates a bad separator, incorrect time unit, or poorly formatted file.

Import a segmentation​

You can import a segmentation when the temporal structure has been prepared in another tool. After importing, check the segment start times, end times and names in the timeline.

An imported segmentation can then be modified like a segmentation created directly in iAnalyse.

A segmentation file contains a first time column, then a column with segment labels.

Example structure:

0.000000    Partie 1
10.011610   Partie 2
26          Partie 3
45.05       Partie 4

The structure of the data in the file must follow the example above.

The supported formats are:

  • TXT, CSV

Import a Scala file​

Scala files allow you to add information related to scales or pitches. After import, check that the values correspond to the musical context of the Project.

The supported format is:

  • SCL

Use imported data​

Once imported, the data can be selected in compatible representations: graph, gradient, fundamental frequency, matrix, chromagram or MFCCs depending on the file type.
