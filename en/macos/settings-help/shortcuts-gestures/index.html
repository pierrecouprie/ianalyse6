Mouse interactions​

Shortcut/modifierFunction
⌘⌃ + arrowsMove selected annotations one step: left, right, up, down
⇧ + click on annotationMultiple selection / add to selection
⌘ + click on annotationMultiple selection, depending on context
⌃ on polygon point / Bézier / cursorRemove a point or keyframe when possible
⌥ on polygon point / BézierChange the point type, e.g. curved/straight
⌘ while moving the start or end (in the timeline) and handles to the middle left and right (slide) of a cursorPreserve internal cursor keyframe positions
⌥ while moving an annotation, slide, marker or segment in timeScrubbing audio while dragging
Escape while creating a line/shapeCancel creation
Double-click while creating a shapeFinalize the creation
Double-click on the segmentation timelineAdd segment
