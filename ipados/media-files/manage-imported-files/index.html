Gérer les fichiers importés

Les fichiers importés sont les sources utilisées par les Documents, les annotations et les représentations du Projet. Il est important de les conserver accessibles pendant toute la durée de l’analyse.

Afficher les fichiers du Projet​

Le navigateur affiche les fichiers disponibles dans le Projet. Sélectionnez un fichier pour consulter ses informations ou pour l’utiliser dans un Document.

Un même Projet peut contenir plusieurs types de fichiers : audio, vidéo, image, PDF, MIDI, MusicXML, MEI ou données.

Supprimer un fichier​

Un fichier ne peut être supprimé que s’il n’est plus utilisé dans le Projet. Si le bouton ou la commande de suppression n’est pas disponible, cela signifie généralement qu’un Document, une annotation ou une représentation utilise encore ce fichier.

Avant de supprimer un fichier, vérifiez qu’il n’est plus nécessaire à l’analyse. La suppression définitive peut intervenir lors de la prochaine sauvegarde du Projet.

Remplacer ou retrouver un média​

Si un média est introuvable, iAnalyse peut vous demander de le localiser. Sélectionnez alors le fichier correspondant à son nouvel emplacement.

Lorsque vous remplacez un média, vérifiez ensuite la timeline, les annotations et les représentations qui l’utilisent. Si la durée ou le contenu du nouveau fichier diffère de l’ancien, certains éléments temporels peuvent devoir être ajustés.

Fichiers liés et fichiers copiés​

Sur iPadOS, la stratégie de Projet influence directement la manière dont les fichiers audio et vidéo sont stockés.

Un fichier copié rend le Projet plus autonome. Un fichier lié limite la taille du Projet, mais il doit rester disponible à son emplacement d’origine.
