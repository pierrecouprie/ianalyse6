Create a Slideshow

A slideshow lets you prepare a time-synchronized presentation. It can contain slides, annotations, images, videos, and cursors.

Create a Slideshow Document​

Create or open a slideshow Document. The slideshow contains slides organized in time.

The timeline is essential for working precisely with slides: it shows their start, duration, and sequence.

Create a Slide​

Place the playhead where the new slide should start, then add a slide. The new slide appears at this time position.

Two slides should not be too close in time. If a slide cannot be created, check the playhead position.

Edit a Slide​

Select the slide or place the playhead on it to display its properties. You can edit its title, start, duration, background, or contained elements.

To edit a slide duration, adjust the start of the next slide or edit the available time properties.

Delete a Slide​

Delete a slide when it is no longer needed. The first slide can have special behavior depending on the Project and should not be deleted without checking the slideshow organization.

Prepare the Presentation​

Use annotations, layers, and cursors to guide playback. Always replay the slideshow from beginning to end before exporting or presenting it.
