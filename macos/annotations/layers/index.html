Utiliser les calques

Les calques permettent d’organiser les annotations d’un Document. Ils sont utiles pour séparer plusieurs niveaux d’analyse, afficher seulement certaines annotations ou contrôler leur comportement pendant la lecture.

Comprendre les calques​

Chaque annotation appartient à un calque. Un Projet simple peut n’utiliser qu’un seul calque, mais un Projet plus complexe gagne souvent en lisibilité avec plusieurs calques.

Vous pouvez par exemple utiliser un calque pour les commentaires généraux, un autre pour les éléments musicaux et un autre pour les indications visuelles.

Créer et renommer un calque​

Ajoutez un calque depuis la zone de gestion des calques, puis donnez-lui un nom explicite. Un nom court et clair facilite la lecture du Projet, surtout lorsque plusieurs personnes travaillent sur la même analyse.

Placer une annotation dans un calque​

Sélectionnez l’annotation, puis choisissez le calque souhaité dans ses propriétés. L’annotation conserve sa position et sa durée, mais elle suit désormais les réglages du calque choisi.

Afficher, masquer ou verrouiller un calque​

Vous pouvez masquer un calque pour alléger l’affichage sans supprimer ses annotations. Vous pouvez aussi verrouiller un calque pour éviter de déplacer accidentellement ses annotations dans la vue principale.

Ces commandes sont pratiques lorsque le Document contient beaucoup d’éléments superposés.

Définir le comportement temporel​

Les calques peuvent contrôler la manière dont les annotations apparaissent pendant la lecture. Selon les réglages, les annotations peuvent suivre leur durée temporelle, conserver une couleur ou une opacité commune, ou adopter une apparence différente en dehors de leur durée active.

Ces réglages permettent de rendre l’analyse plus lisible pendant le déroulement du média.
